# AVthing

瀏覽器擴充功能與小工具，全部開源（AGPL-3.0）。

| 專案 | 說明 |
|------|------|
| [QuickLinker](https://github.com/avthing/QuickLinker) | 偵測頁面上的編號，一鍵跨站搜尋並檢查連結可用性（Chrome 擴充功能） |
| [PreviewImageSaver](https://github.com/avthing/PreviewImageSaver) | 在影片頁一鍵把封面與全部預覽圖存到指定資料夾 |
| [subtitlecat-ext](https://github.com/avthing/subtitlecat-ext) | 依番號從 subtitlecat.com 抓中文字幕並掛到播放器 |
| [costars-tool](https://github.com/avthing/costars-tool) | 合作關聯圖：2D／3D／4D 的離線互動視覺化 |
